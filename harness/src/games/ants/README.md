# 蚂蚁搬家试玩

运行 `npm run serve`，从大厅进入蚂蚁搬家，或访问 `/ants`。

六只蚂蚁固定抓握一个刚体的六个位置。每只选择八方向单位拉力或松力，
引擎累加合力和力矩，用带碰撞检测的过阻尼运动推进，没有自动过门或转身。
三关为长条过窄门、U 形挡板回退绕行、T 形物体穿错位双门。
整块物体进入终点获胜，180 秒超时。

- 真人：点击编号或 1—6 选择；点击场地设置持续目标，到达后自动松力。
  目标连线与编号可见；X 取消选中蚂蚁目标，空格全部取消。方向按钮折叠在辅助操作中，
  方向微调 / WASD 仍保持 4 秒。目标控制不自动绕障，仍受合力与刚体碰撞限制。
- 离线算法：公开关卡的固定路线控制器，使用相同的六蚁动作与碰撞。
  用于玩法演示与验证可解性，不是通用规划基线。
- Jev / DeepSeek：复用大厅已保存的后端配置，每只蚂蚁单独创建后端与
  request manager，收到物体世界坐标、自身世界位置、力臂、各候选动作的力矩和队友当前拉力。
  六路独立调度，每只完成后间隔 1 秒再请求，不等待最慢成员；每只最多 30 次、全局最多 180 次请求。
  动作有效 4 秒；回复期间物体移动超过 65 像素或转动超过 0.55 弧度时只记录、不执行。
  12 秒请求超时；静止场景的慢回复仍可执行。只问拉力一个问题，避免 DeepSeek 对附加信号另发请求。

`/api/ants` 是独立试玩会话，尚未纳入通用 benchmark / CLI 游戏注册表。
物理在服务器运行；30 秒无轮询会停止，5 分钟后清理会话。
页面可以导出本局状态和模型决策 / 真人输入 JSON；当前不持久落盘。
报告 token 包含返回但未执行的回复；任一请求缺少用量或失败则总用量未知。
费用未知，不填零。该试玩不提供已验证的模型性能排名。

验证：`node --import tsx --test test/ants.test.ts`。
包含六个独立模型实例、用量归属、手动覆盖拒绝、力矩、动作到期、
阻挡不可穿透以及三关通过实际力学动作可达终点。

实验参考：

这是游戏改编：没有自由走动、换抓握位置、生物蚂蚁的局部感知模型；
第三关是适合试玩的 T 形双门变体，并非论文几何尺寸复刻。
