# Annie 主播嵌入组件

源码完整版和 EXE 拆分完整版共用 `src/deskfront/session-launch.ts` 自动启用主播、解说和弹幕。宿主从本局报告的 enginePid 定位窗口：直接游戏进程或其直接 DeskfrontGame.exe / Godot_*_win64.exe 子进程，不扫描并附着其他用户游戏。源码 Godot 控制台启动器本身没有游戏窗口，因此必须识别其游戏子进程。两条路径使用同一套人物、语音、台词和动作实现。

用户修正（2026-10-12）：沿用游戏原有底部白字深底字幕，人物半身像紧贴字幕左侧、底边对齐。字幕由游戏原生层绘制且只有一份；主播宿主只画人物，不再提供右下角卡片、标题、收起按钮、重复字幕或常驻等候面板。读取原生字幕矩形与视口尺寸，换算到实际客户区；缺少有效坐标时保持隐藏，不猜测位置。启用人物时，音频准备完成后预留900毫秒出场窗口，再提交原生播放；实际出场提前量受400毫秒状态轮询影响。真实解说结束后人物继续停留2秒，暂停、换局或失联直接隐藏。空闲时停渲染，保留轻量状态查询以唤醒下一句。角色渲染上限30fps、像素比上限2、禁用实时阴影。原生层逐像素透明：隐藏的WebView输出RGBA小画面，预乘Alpha后使用UpdateLayeredWindow绘制到游戏的透明子窗口，游戏从人物周围和发丝边缘透出，不采用黑底或色键抠图。最多20次/秒且只允许一帧在途，闲时停止；透明窗不接收鼠标。默认人物宽度按窗口自适应到140～220像素，并受字幕左侧可用空间约束；镜头和半身像沿用已有表现。

当前紧凑字幕按视口使用13～15号字体，最大宽度28%，左沿为视口40%，底边距视口底部118像素。每次原生容器尺寸变化后，根据实际高度重设位置，避免换行或延迟排版让底边漂移。JEV动作先排队，收到真实音频播放状态才启动，记录motion-started及一秒后的motion-sampled骨骼变化；表情选中不等于动作播放成功。每句最多一次JEV，出场及退场不增加模型调用。

2026-10-15 首帧定位：预备出场直接使用本局当前原生字幕布局，与正式说话使用同一锚点。仅同局两秒退场可保留最后有效布局；暂停、禁用、换局和过期时清除。宿主先定位，再绘制属于当前发言且尺寸匹配的新透明帧，最后显示；旧发言或旧尺寸帧不能触发显示。原生宿主通过带修订号的frame-layout告知实际像素尺寸，渲染器按此尺寸构图并回传修订号；不将网页CSS像素当作Windows窗口像素，支持显示缩放。隐藏时保留位置，下一句不从屏幕外移入。源码版和EXE版共用这套协议与原生底边布局。

2026-10-12 陪看表现：保持透明人物大窗口，镜头中心下移至1.22，距离1.65，让手部更易进入画面。一次JEV请求含face、clip、accent、energy，accent可为空，在语音约55%以后且开场动作已结束、剩余至少2.2秒时执行；不重复相同动作，不抢同一骨骼。自然伴随手势由实际音频起音继续驱动，中文标点与强调词已适配；文本进度按音频时长估算，尚非逐字时间戳。日志新增talkGesture及调度统计，不能用头部变化替代手部观感验收。语音选用已实测可调用的Vivi 2.0，speech_rate=8，发送陪看口吻及句子情绪指令；私人音色配置仍只存在.env。
