# 战术小兵：可信行为与弹道散布

> 历史记录：本文描述当时的会话副本范围。当前所有权、事实源和可重构范围以 [所有权与模块化边界](deskfront-ownership-boundary.md) 为准。

目标优先级改为行为可信、行动连贯、协作可读和观赏性，胜负保留为场景结果。指挥与单兵提示已同步；不通过随机犯错制造表演。

Harness 的 human_unit.gd 恢复自动姿态下受压匍匐：强压制、近期受火的紧急自保或卧倒后的受压恢复期可以爬行；安全移动恢复原生姿态。显式姿态、掩体探头缩回、建筑姿态沿用引擎。原生找掩体和紧急自保没有删除。抱团目前是模型协作指导：独立站位、避免挡枪、保持照应；没有强制让全队共享一个目的地，也没有重新启用一套自动编队来覆盖 JEV 命令。

human_combat_fx.gd 对每发远程弹丸进行瞄准平面内的对称圆盘散布，以角度定义散布，随距离扩大并受射手压制影响。原 accuracy 用作散布参数，不再是保证命中的概率；旧 landed 抽签不控制弹道。近战保持原样，沿用连续弹丸碰撞、掩体遮挡、友军阻挡与爆炸溅射。卧倒收益来自原生身体碰撞体，没有额外减伤倍率；收益随射角、距离和武器变化，爆炸仍可能命中卧倒者。散布参数是首轮设计值，尚未完成武器平衡调优。

接入三对五/战术启动器及无限世界会话副本，原游戏仓库没有新增修改；原先 scripts/unit.gd 的未提交改动保留。已运行会话不会热加载，需要新开局。普通非战术启动路径不在本轮范围。

验证：human_combat_probe.gd 在实际 Godot 中检查受压爬行、脱险恢复、显式姿态，以及步枪、火箭、炮弹、手雷都有散布。固定正面射位每姿态 4000 发几何采样：站立 3667、蹲姿 3657、卧姿 2865 次碰撞命中，卧姿相对站姿少约 22%；不是实战命中率或多角度普适结论。Harness 战术 65 项通过；原引擎语义 113 项通过（输出重定向到 Harness）；Python 控制 10 项与 LM 15 项通过。全量上游 Python 测试未全过，存在 Windows SQLite 临时文件占用及 Godot 路径配置问题。未完成真实模型整场观感验收。

调度讨论：当前 EXECUTOR_INTERVAL 仍为 0.5 秒。下一步可采用约 5 秒常规复核，加新威胁、掩体失效、队友阵亡、到位和路径失败事件触发。工程负责即时身体反应和事件检测；JEV 决定继续、换位、等待或撤退。需要事件合并、阈值滞回、旧回复失效与有效动作保持，不能只把常量改为 5。
