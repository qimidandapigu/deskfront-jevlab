# Harness 威胁预测与执行自由度

2026-09-20。本轮只修改 quickplay-harness；游戏项目源文件未修改。

## 职责

- DeepSeek：10秒指挥周期，选择整体策略与路线分工；收到当前位置风险、当前移动目标风险和各路线入口风险。路线入口不代表当前任务的下一步。
- JEV：整队一次请求，完成后至少1秒再调；每兵选择动作。指定路线与有效射位、撤离位置同时保留，不再删除所有其他推进选项。
- Harness：每游戏秒用原生射界和寻路生成风险。发出命令前继续原生可达性检查和队友位置冲突检查；预测不自动替换模型动作。

## 数值含义

`standing_exposure` 列出站姿射线可达且在敌方射程内的敌人、武器单发伤害、冷却/装填剩余时间。它不要求已经掉血。准备时间不包含转身、瞄准、AI反应、友军遮挡与弹丸飞行时间。

`current_goal` 和候选位置的 `risk` 沿原生路径等距离抽样12个中点，计算预计到达秒数、暴露秒数、途中最大威胁人数和终点威胁人数。速度采用当前步态、压制和编队倍率。敌人位置固定，射线采用站姿高度；未预测命中概率、未来走位、爆炸溅射或回血。零暴露仅代表抽样没有发现威胁，不是安全保证。

仅对查询过的同一落点附加风险。未查询的推进/目标位置明确标为未知。候选详细几何留在工具端，JEV只收到简短数值描述；DeepSeek不接收候选网格和完整掩体部件。

执行验证请求改为临时文件写完后替换，避免Godot读到半份JSON。原生验证与风险预测独立：可达不代表安全。

## 验证边界

Python回归验证指定路线不会吞掉射位候选、风险进入真实整队请求视图、邻近但未查询位置不会继承安全值。Godot threat_probe使用真实原生射线与武器配置、固定测试路径，验证尚未受伤就检测到威胁、冷却数值、暴露路径、墙体遮挡和只读属性。该探针不是整局胜率测试。

保留3对5、双方同战斗数值和脱战每秒2血。单局有利结果不能证明稳定胜率，后续需要相同地图/初始条件下重复对照。
