# 同目标期限与受阻分层处理

本轮完成：

- 同一区域的计划保留原复核期限，改写目的或切换阶段不再刷新期限。
- 已处理的期限事件不因同区域回复每轮重复触发；正常复核和新事件仍有效。
- 中间目标已到达或接近持续停滞时，不能再次提交同区域的 approach/probe/reposition；可选新区域或有事实依据的其他阶段。保持引擎自保，不强制冲锋。
- participation_gap 先唤醒小队；具体成员连续 12 游戏秒没有测量进展，或持续受压事件，才同时唤醒战略层。新命令 ID 不清空进展历史。
- 游戏标记区分“最终目标：占旗”和各队“阶段位置/占旗接近点”。
