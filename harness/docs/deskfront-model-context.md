# 模型上下文清单与取舍

## DeepSeek

mission：关卡类型、目标、关键守军/出口状态，不传生成关卡完整 spec。
objective：目标位置/半径、旗点归属、争夺状态、倒计时；不传屏幕坐标和各方重复 alerts。
units：单位身份/武器/血量/弹药/压制/姿态/位置/目的地、最近实际开火、路径/射界/阻挡/回血状态。
terrain：附近最多12个普通掩体的精简字段；建筑零件合并为整体包围范围摘要，绝不冒充精确可走地图。
routes：路线名称、用途、首尾、路点数和长度，不重复每个路点。
previous_plan、execution、recent_events：原计划、各成员实际任务/火力/风险/停滞、最近6事件。
threat_forecast：工具计算的站姿威胁、敌武器准备时间、当前目标路径暴露，以及各路线入口风险。不是确定伤害预测，详见 deskfront-threat-forecast.md。
输出仍为 strategy 与整队 deployment 选择。

## JEV

每轮单份共享 run/tick/time/bounds/目标、全队和敌方的精简状态、相关地形、DeepSeek计划、执行规则、队友状态。
每兵局部字段：持续任务、停滞与掉血反馈、拒绝原因、距离偏好/当前威胁/受阻目标、目标血量和队友交火比较。
每兵一道动作选择题：候选位置的路程、可射目标、威胁与风险说明。通用操作规则仅在共享状态出现一次。
指定路线不再删除其他推进射位。已查询落点附预计到达/暴露秒数、途中最大威胁人数、终点威胁人数；其他落点明确写未知。
精确命令坐标和原生几何保存在执行端，模型只需返回候选ID。展示数字保留3位小数，不改实际命令精度。

## 不传给模型的原始细节

骨骼、动画资源、模型网格、完整建筑部件列表、ray_size/碰撞盒/渲染字段、精确屏幕坐标、重复候选命令副本、历史中的整套旧候选。

## 2026-09-30 请求压缩边界

单兵请求给 JEV 的 `candidate_sites` 是只读精简视图：保留候选 ID、区域、位置、路程、目标距离、任务距离变化、掩体和可射目标；空的 `cover_id`、空目标数组、零攻击者和未发生的访问时间不再发送，坐标只保留三位小数。完整原生候选仍留在 Harness 请求对象中，用于提交前复验，不能把这次压缩当作删掉可选行动。

个人 JEV 只在首次任务、职责/路线/目标事实变化或反装甲等事件时提前唤醒；同一职责的新 order 只用于过期回执校验，不会让所有士兵重新确认。稳定的观察、开火职责和受阻状态保持当前动作，周期复核为 8 秒；引擎自保和事件唤醒仍即时。无限推进的红绿控制器共享同一原子请求额度。

空间搭建仍保留中文资产名、卡片精确几何、方向证据、规划桌任务、材料分布和路线字段；只去掉资产尺寸的重复副本、旋转标签中的重复度数符号及每格说明的重复尾句。搭建输出的高峰主要是 Choice 对所有卡片/方向返回概率表，不能把它误判成模型写了同样长的方案说明。

DeepSeek 指挥与体验分析边界（2026-09-30）：

- `commander` 是当前战斗的小队级区域/阶段规划；输出仍只有 `region_id`、objective、risk、stage、wait_for。JEV 负责成员意图与路线选择，引擎负责导航和执行。
- `experience_analyst` 只分析当前关的节奏和下一关体验目标；它不选卡片、位置或兵力。无尽推进的关卡策划和空间搭建是另一条 JEV 通道，不能把那部分 token 归给 DeepSeek。
- 旧长回放中 DeepSeek commander 成功 28 次，共 228,006 prompt、7,252 completion；另有 5 次体验分析，共 19,698 prompt、9,323 completion。31 次 commander 请求中有 3 次超时和 1 次区域回执失效，失败请求没有 provider usage，但仍计入运行请求。
- commander 的旧上下文平均约 19,259 字符，最大 28,168；`soldier_reports`、展开的 `engine_squad.assignments` 与重复区域说明是主要冗余。新的 `_commander_context` 只把规划需要的成员状态、目视接触、受压/火力证据、职责/保护状态、当前计划和区域连通性发给 DeepSeek；完整快照仍留在请求对象供验证和回执使用。用旧长回放离线重放，31 份上下文由 597,026 字符降到 285,248 字符（约 52.2% 静态载荷下降），这是压缩估算，不等同于新 provider 的实际计费 token。
- `experience_analyst` 的 `current_design` 只去重每格重复的材料证据，上一轮理解只保留阶段、节奏、当前分析和下一目标等字段；不删除路线、材质主物件或战斗结果。旧 5 次样本的宏观上下文约减少 11%–15%，输出中的 reasoning token 仍由模型决定。
