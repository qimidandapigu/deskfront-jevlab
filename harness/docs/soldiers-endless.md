# 玩具兵无尽生成实验

入口 `/game/soldiers-endless`；经典玩具兵页面有入口。与经典模式共用战斗引擎，独立会话。

运行 `npm run serve` 后访问对应端口。此次交付实例使用 3787，保留原来的 3777 服务。

## 玩法与生成

WASD / 方向键移动，空格 / J 持续射击，R 换弹。向上不断前进，镜头跟随角色。地图按 20 行区段在前方无缝拼接，不需要清场或点击切关；角色位置、血量、弹药、换弹与计时持续保留。阵亡结束，本模式没有三分钟战斗上限。

模型选择前方区段的通路、密度、阵型、强度和六个局部掩体形状。区段接缝保留全宽通道；前方不足时同步生成规则地形，避免等待模型挡住前进。迟到的模型结果用于后续区段。右侧保留模型输入、返回和来源记录。距离玩家后方超过 30 格的旧地形和敌兵回收，已回收区域不可返回。

模型接收生命、累计受伤、用时、移动比例和最近布局。低血量保护覆盖不合适的强度。8 秒超时使用规则回退；最多 100 次模型请求后仍继续规则生成。随机模式作为对照。强度仅影响新增敌人，不在拼接时恢复生命或重置弹药。

本次连续地图服务入口：http://127.0.0.1:3779/game/soldiers-endless 。原 3777 / 3778 实例未重启。

## 验证与限制

连续地图改造：类型检查和 33 项相关测试通过，覆盖无敌人时跨接缝移动、超过旧时间上限继续运行、200 段地形回收。以下分关实测是改造前记录，不代表连续模式验收。

- TypeScript 类型检查通过；相关 31 项测试通过。
- 1000 个随机种子检查通路、出生点、确定性和布局变化。
- 早期引擎版本离线脚本连续打通 10 张恢复难度地图；同一工作区随后更新了战斗规则，这项结果不能作为新版难度证据。
- 最新战斗规则下实际 HTTP 游戏循环完成 2 关并进入第三关，测试脚本随后阵亡；真实 Jev 调用及换关已验证，证据见 `output/endless-live-evidence.json`。
- 两种玩家状态的真实模型对比见 `output/endless-profile-evidence.json`，初次失败保留于 `output/endless-profile-before.json`。
- 初版提示曾把濒死状态对应为下一关挑战，澄清当前状态与下一关目标后，本次样本改为恢复关。两例样本不能证明总体准确率。
- Jev 对形状明显偏爱 corner，持续内容多样性尚未得到验证；无尽循环不等于无限原创内容。
- 下一关按请求时的快照生成；之后本关表现不会重新生成已就绪地图。没有运行时生成新美术、角色模型或动画。
