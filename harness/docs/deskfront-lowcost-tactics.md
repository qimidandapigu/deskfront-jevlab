# 低计算量战术查询

本轮选择降低非紧急查询精度与频率，不增加模型规模。

- 危险地图：威胁位置量化 0.1→0.2；变化时重算间隔 0.75→3 秒，静止威胁不重算。地形 revision 改变仍立即失效。
- 危险评分：4×4→8×8 区块；实际导航细网格、墙体碰撞、子弹与爆炸安全检查不降精度。
- 网格复用：只有首次或地形改变时分配并填充障碍网格，平时复用 AStarGrid2D；只写入危险权重变化的区块。
- 失败掩体查询：条件未变时缓存 1.5 秒；期满重试，并记录 cover_calls、cover_us 和 max_cover_us。
- 找掩体：完整路线验证候选数 8→3，可能错过更优掩体，失败仍报告，不能把不可用位置当安全。
- 普通射界复查：0.4→0.8至0.95 秒，按单位 ID 错开节奏；每次实际射击仍做安全验证。
- 小队战略路线复查：2→4 秒，保留已有路线；地形 revision 改变立即重算。

预警与缓存 13 项（含网格复用）、战术安全 18 项、语义 114 项和 Python 接口 19 项通过。
本轮尚未引入每帧硬预算或后台线程，因此不能保证所有同步查询均低于帧预算。实测数据另存 output/lowcost-evidence.json。
