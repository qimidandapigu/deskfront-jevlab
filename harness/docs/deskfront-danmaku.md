# 模拟观众弹幕

弹幕单独调用已配置的 `commentary` 模型后端，使用非思考配置。输入复用真实战况摘要和最近15条短评；不向指挥、小队或意图执行器发送命令，不进入语音合成。

网页解说面板新增“开启模拟弹幕”和密度选项。AI 观战新局默认开启、低密度；可随时关闭。需要新启动的游戏副本加载 `HarnessDanmaku`。旧副本没有就绪回执时不会调用模型。

- 有宏观战况变化才请求，两次开始至少间隔15秒；全局最多一个弹幕请求，每局独立30次，开关不重置。
- 单次生成最多5条，低密度最多3条、间隔6秒；普通密度最多5条、间隔3秒。事实不足允许少生成。
- 请求超时3.5秒。模型返回需要带已知事实ID；过滤无效结构、过长文字、重复原文。ID校验不能证明模型语义绝对准确，仍需实战检查。
- Godot纯显示层每250毫秒检查一次命令，同屏最多3条、单条7秒，标注“模拟弹幕”；没有寻路或物理查询。
- 暂停、换关、结束、关闭时清空旧内容，忽略过期模型回复。HTTP 402或鉴权错误关闭自动调用，429延后重试。
- 记录在 `logs/danmaku/<session>.jsonl`，包含事实、耗时、模型与token用量（供应商返回时）、批次及安全的错误分类。文件回执在对局目录的 `danmaku-status.json`。

验证：TypeScript检查、弹幕生命周期与原解说测试、Godot原生显示生命周期测试通过。2026-09-29使用已录制战况做真实模型请求，接口返回HTTP 402，尚未验证真实模型生成及实战观感。没有修改参考游戏目录。
