# 迫击炮据点与夺取

坦克关的迫击炮初始属于红方，由两名真实敌方士兵操作。两名炮手计入该关守军和人数预算。我方不再获得免费迫击炮或额外炮手。

无尽推进的初始绿队改为五人：两名步枪兵、两名冲锋枪兵、一名火箭筒兵。首次实际遭遇仍为三名守军，不自动补员；后续增援仍使用现有生成预算和六人上限，不保证每关恢复五人。夺炮占用其中两名现有士兵。

清除或撤离全部炮手后，炮留在原地成为可夺取装备。尚有一名炮手时保持原方所有权，但停止射击。炮架被摧毁后不能接管。

接管条件对红绿双方相同：两名存活、非火箭兵、没有其他设施任务的步兵进入炮位 0.24 范围，压制低于 0.5，且未在即时避险、投雷或驻防；0.40 范围内不能有敌人争夺。相同两人持续保持 3 秒后完成接管。人员离开、更换或出现争夺使进度清零。接管保留炮架当前血量，不补兵，不传送现有士兵。

接管后的两名士兵退出原小队分工，沿原生设施操作路径完成最后就位，架设 4 秒后可开火。其余成员保留原任务。炮管转向、逐发瞄准、10 秒装填、无限普通备弹，以及友军爆炸安全检查沿用现有实现。双方都依赖友军真实视野，接管本身不会获取敌人坐标。

炮管和双脚架在固定底盘上转动，炮口位置继承真实转角；炮管显示短暂后坐，射击仍需完成对准。迫击炮使用有朝向的低多边形炮弹，沿原有高弧线飞行；坦克炮弹保持原有直射轨迹。连续尾迹只画物理碰撞扫描已经走过的段，并按现有效果池预算回收，不画预测命中线、不追加伤害，也不改变弹速、射程和装填时间。

Harness 给指挥、小队与个人模型提供当前已发现的装备事实和经引擎验证的接近候选。模型决定是否接近、打掉炮手、安排两人接管以及掩护；引擎只按实际位置、存活、争夺和时间判定接管。没有替模型自动选择夺炮路线。

双方迫击炮直击伤害为 36，满血 50 的步兵不会被单发直击瞬杀。普通射速仍为 10 秒一发。开火会向受击阵营暴露该固定炮位，使模型可以依据真实开火来源组织反击；该炮位情报持续到下一次关卡重新部署，不提供其他敌人的位置。

意图执行器仍只管理意图及执行状态。设施接管时通过现有取消入口释放这两名士兵的移动、姿态意图，并解除其小队成员关系；完成接管后的短距离就位复用原生炮组设施驱动，不引入另一套战术 Agent。关卡重新部署属于世界生命周期，新坦克段重新放置敌方炮位。

验证包含敌方初始占用、禁止隔空夺取、部分炮手存活、人数不足、争夺中断、持续接管、原有成员接管、保留血量、禁止传送、释放执行权、实际发射命中、双方重新夺取和炮架摧毁等原生场景。自动测试和模型实战需分别报告。
