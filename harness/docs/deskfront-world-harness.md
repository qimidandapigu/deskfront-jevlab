# 无限生成：绿色接回现有 Harness（历史记录）

当前对外入口、默认坦克规则和能力边界以 [Deskfront 当前版：无尽推进](deskfront-current.md) 为准；本页只保留旧接入记录。

当前生成演示改为开场 3v3，每段三名准备就绪的守军（两名前排、一名侧翼）；保留地形及双路线。验收重点是构建、部署、连通性和设计表达，不以模型胜率作为关卡生成验收指标。战损仍延续，不额外复活或补兵。

此版本替代“两边均为本地 Bot”的默认行为。`greenController=harness` 为默认值；`local` 保留旧版对照。

- 绿色：复用既有 `CoordinatedController`、共享 `Game.ask`、DeepSeek commander 与 JEV executor 路由，使用已有模型配置。
- 红色：继续原生本地 Bot，不请求模型。
- 生成：保留 DeepSeek 节奏、JEV 构建选择，和绿色战术决策共用会话请求预算。绿色接入后会增加模型用量。
- 引擎：绿色设为 lm 控制，固定推进脚本不再覆盖绿色命令；原有射击、导航、动画和单兵自保仍由游戏执行。模型没有直接修改生命值或世界状态的权限。

指挥上下文使用本段守军、生成结构、真实战况和最近执行反馈。执行候选增加本段正面、侧路与出口，复用原生可达射位和后撤位置查询。目标为清除守军并抵达出口，删除占旗动作及倒计时提示。每次新区完成更新绿色控制版本，旧决策由引擎拒绝；红方和观战输入不能冒用绿色控制。

验证（2026-09-20）：

- Godot 7 项 Harness 权限/不覆盖/过期命令检查，41 项原构建合约，113 项战斗语义检查通过。
- 3 项遭遇上下文检查、25 项共享战术检查、9 项导演检查和 TypeScript 类型检查通过。
- `output/world-harness-1789902395901/report.json`：真实 Godot、离线后端接入与绿色执行回执通过。
- `output/harness-green-check/real-report.json`：真实共享 DeepSeek/JEV 调用、绿色 lm / 红色 game_ai，以及绿色移动、攻击、掩体命令接受记录。本次真实试跑上限 60 次请求。

实测仍出现绿色重复找掩体、推进不足，不将“命令被接受”作为战术效果合格的证据。长期胜率、协同与 token 效率尚未验收。
