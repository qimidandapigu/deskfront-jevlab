# 意图执行器（IntentExecutor）

这是用户确认的命名及职责约定。适用于后续任务、开发者与代理对 Deskfront 执行模块的修改。与旧文档名称不一致时，以本约定为准。

## 定义

**IntentExecutor = 意图缓冲区 + 执行状态机。**

- 意图缓冲区：接收、暂存、合并、替换或丢弃指令，拒绝过时版本；不是无限先进先出队列。
- 执行状态机：按已定义的优先级和条件管理执行、挂起、重新验证、恢复、完成、失败和取消；反馈实际状态。

它不调用模型，不思考战术，不选择战略区域，不重新分配小队职责，不等同于士兵 Agent、行为控制器或 Harness。执行权仲裁是机械执行规则，不是新增决策层。共享事实板为它提供输入，但不属于本名称所指的两个组成部分。

## 边界

DeepSeek 规划阶段目标区域，小队 Jev 从导航算法提供的可达路线、经过区域和分叉证据中选择成员、职责、局部目标区域及路线组合，个人 Jev 提出局部意图；Harness 负责上下文、通知、模型调度、预算、组合质量诊断和回执传递，不因分路不理想而拒绝可执行选择，也不代替 Jev 暗中改派侧翼路线。IntentExecutor 管理意图进入实际动作的生命周期；引擎执行导航、碰撞、射击及安全验证，并提供世界事实。

急迫危险可按规则中断普通动作；恢复前必须重新验证当前条件，不能重放旧路线。等价指令不重置执行期限；新的任务版本不得复活旧任务。接收、执行中和完成必须区分，不能把入队当作成功完成。

## 当前实现与迁移要求

Harness 现在把独立的 `src/deskfront/world/intent_executor.gd` 安装到每局临时引擎副本，由 `human_squads.gd` 持有。它统一记录小队/个人移动意图、固定执行期限、换令/失去掩护/撤销时的取消、主动起立建立射线的姿态意图，以及真实开火或被挡的回执。`accept_personal`、`update_personal`、`personal_transition` 继续管理个人意图的挂起和恢复；恢复时重新校验原生候选位置，候选过期则失败并让 Harness 重新选择，不复用旧路线。重复的等价移动请求不续期。

当前受管移动优先级为个人选点 50、交替推进 40、寻找射位 30、区域驻守 20、编队移动 10；仅在同一任务版本和仍有效的路线内比较。个人选点包含快速移动、卧姿接近、占掩体与探头攻击，选点必须来自引擎候选并在下达时复验。爆炸避险、生存撤退、死亡由引擎即时处理并中断普通意图，不等待模型或上述排序。自动瞄准、弹道、实际开枪也仍由引擎执行；IntentExecutor 只记录开火回执，不能把它宣称为弹道执行者。关卡切换与生成期间的路线重置属于世界生命周期，尚未迁入逐兵战斗意图缓冲。因而这不是整个引擎的单写者改造，也不代表旧运行进程会自动加载新脚本。

引擎适配器中的卧倒恢复（2026-09-28）：因命中或压制实际进入卧姿后，最短保持 3.0 秒；之后还需最近真实威胁已过去 1.5 秒，且压制降至恢复阈值，才恢复普通姿态。近失弹/命中更新威胁时间，重复模型命令及查询不续期。自动射界调整不能抢先起立；不重启已保持的卧姿动画。炮弹逃离和紧急撤退可立即蹲跑，翻越、驻防、投雷、近战、死亡及明确的玩家姿态输入保留原生优先权。它是引擎执行的姿态稳定规则，不新增 Agent 或战术层；IntentExecutor 仍只管理意图及执行状态。

后续新增受管移动必须优先复用现有仲裁入口；若需要直接写路线，应说明为何不属于该入口适用范围，并验证不会覆盖其他执行者。将来拆出模块时使用 IntentExecutor 名称，保留现有协议兼容性，不为统一名称盲目批量改类名。

实现历程见 [执行状态与意图缓冲](deskfront-execution-state.md)。本次文档统一不会改变运行中的进程；新任务需要读取项目 AGENTS.md，已运行任务需显式重新读取约定。


到位保持（2026-09-29）：个人选点、寻找射位和驻守的路径结束后，只有实际处于引擎目标附近且无路径失败，才进入 `holding`。同一命令内低优先级移动不能把士兵拉回，等价提案不续期。保持默认 6 秒供执行和观察，真实开火延续 6 秒；枪口被挡、地图导航版本改变、离开保持位置、危险、死亡或明确取消会释放／中断。无真实开火则到期记录 `hold_review_due`，不无限占位；不自动选择替代位置或重放路线。新命令版本仍可接管，同来源明确改变目标仍可接受。本改动不调整小队发令频率、命令版本生成或模型策略。每次观察只检查当前士兵的常数个字段，不新增寻路、全图扫描或模型请求。

反坦克冲刺（2026-09-30）：只有个人 Jev 选中引擎已验证的反坦克接近点、目标坦克仍可见、炸药包可用且士兵状态允许时，`rush_to_site` 才获得最多 4.5 秒的冲锋承诺。期间单次命中、普通枪火和单纯靠近坦克不使士兵自动卧倒或掉头；迫近爆炸、残血、强压制、目标死亡、动作完成与换令仍终止或中断冲锋。意图执行器只记录短时动作的执行状态，安全例外由引擎规则实现；这不是自动选择炸坦克的战术决策。进入真实投掷距离后由个人 Jev 再选择 `satchel`，引擎复验视线、友军爆炸风险及冷却。
