# 动态区域与任务反馈

区域目录现在同时包括兼容旧计划的路线区域及覆盖snapshot.bounds的0.3世界单位定位网格。网格ID锚定世界坐标，扩图保留已有编号；区域边界由当前地图裁剪。定位网格不宣称可通行，障碍拓扑与安全性仍需原生查询，尚未实现按导航连通性自动合并战术区域。

共享状态每次构造时读取最新目标位置、目标存活/射界状态及navigation_revision。射界状态或导航版本变化触发指挥重评；JEV收到dynamic_task和变化记录。目标死亡保留原ID用于完成验收，不虚构新目标。模型回包仍走现有最新状态校验。

等待区域到达使用同一目录边界。48项针对性测试通过，包括边界覆盖、扩图编号、敌人移出射界和死亡。未运行新真实模型对局，不能据此声称战术表现改善。
