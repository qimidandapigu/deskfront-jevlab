# 执行耗时与射位短移

新增 execution_profile，记录弹道、小队、原生战术、士兵更新各部分调用次数、总耗时与最大耗时。统计不包含全部渲染、独立动画回调、序列化及网络，因此不能把它当全帧耗时。

短规则探针只运行到 2 游戏秒：121 次更新，士兵总计 1.10 秒、最高 16.3 毫秒，小队最高 82.3 毫秒。数据见 output/performance-profile-before.json。这不足以解释战斗阶段 4–6 FPS，不能当性能验收。

实改：
- 目标搜索把距离和兵种过滤前置，避免为射程外敌人重复计算阵营视线；实际射击安全校验保持不变。
- cover 意图下找不到预设射位时，尝试最多三个 0.075 的侧移/后退候选。要求真实射界、可直达、站位无冲突；实际导航路程 <=0.13、暴露路程 <=0.06；沿用已有查询冷却与移动仲裁，不向前冲。
- 所有候选失败仍报告 no_safe_firing_position，不伪造执行成功。

小队合同 62、语义 114、接口 19 项在初版短移改动后通过；收紧实际路径验证后战术安全 18 项通过。接口仍有既有 SQLite ResourceWarning。

本轮没有完整真实模型前后对照；不能声称卡顿或无效射位已全部解决。下一步用新增分段数据定位战斗开销，并为短移候选做专门场景验收。
